A thing that makes some redundant parts of the `project.json` match with each other, and deletes some unnecessary or problematic things from it.

How to compile:
- copy the files from the `src` folder, and copy `gzip.js` from the root folder into your folder
- make a directory called `compiled` inside it, this is where TypeScript will put the compiled files
- copy the `index.html` into the `compiled` folder
- run the TypeScript compiler
